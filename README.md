SentinelIoT

An AI-Enhanced Adaptive IoT Honeypot built using FastAPI.

Features

- Simulated IoT Camera
- Security Dashboard
- Credential Capture
- Request Logging
- Modern UI
- AI-ready Architecture
- SQLite Integration 
- Threat Analytics 

Tech Stack

- Python
- FastAPI
- Jinja2
- HTML/CSS
- JavaScript
- SQLite 



Built as a Cybersecurity & IoT Research Project.
